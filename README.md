## 📂 Our Projects

Below is the list of projects available in this repository, covering areas like industrial automation, embedded systems, machine learning, and software development:

### 🏭 [Advanced Automation](./Project_AdvancedAutomation)
* **Description:** Complete automation of an industrial manufacturing line.

### ⚖️ [AutoBalanx Production Line](./Project_AutoBalanx_ProductionLine)
* **Description:** *Work in progress (Data yet to be added).*

### 📱 [FoxLine](./Project_FoxLine)
* **Description:** Development of a mobile Android application that facilitates internal communication within workgroups.

### 🎛️ [FoxMix](./Project_FoxMix)
* **Description:** Digital mixing desk developed in Python with a Tkinter graphical user interface. It allows simultaneous playback and mixing of two audio tracks.

### ⏱️ [FreeRTOS Baremetal](./Project_FreeRTOS_Baremetal)
* **Description:** Implementation of the same embedded system using two different approaches, allowing for a direct comparison between Bare Metal and FreeRTOS.

### 🤖 [Kuka Recyclable Waste Separator](./Project_Kuka_RecyclableWasteSeparator)
* **Description:** Automated recyclable waste sorting system that combines a KUKA SCARA robotic arm, computer vision, and a Sysmac PLC controller.

### 🧠 [Material Classification TinyML](./Project_Material_Classification_TinyML)
* **Description:** A cyber-physical system for the autonomous classification of three materials — Wood, Metal, and Fabric — in the context of Industry 4.0. The core approach is based on Sensor Fusion.
