# **WCom - Internal Communication Application**

This repository contains the project developed as part of the Mobile Computing course in the Master's Program in Electrical and Computer Engineering (MEEC) at IPCA, academic year 2024/2025.

## **Project Description**

* The goal of this project is to develop a mobile Android application that facilitates internal communication within workgroups. The application implements features such as authentication, message exchange (text, image, audio, and video), and user profile management.





> [!TIP]
> Developed in Android Studio with Kotlin and using Firebase.
